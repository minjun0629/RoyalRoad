# 05. 현황 감사 — 정식 출시 사양 대비 (0.4.0)

정식 출시 사양(1~35절 + NPC 12-A~12-U)을 지금 코드와 하나씩 맞대어 본 결과다.
**구현** = 서버 로직 · 저장 · 화면(또는 명령)까지 이어져 있고 테스트가 있다. **부분** = 핵심은 돌지만 사양의 일부가 없다. **없음** = 아직 코드가 없다.
YAML 에만 있고 로직이 없는 기능, 버튼만 있는 화면은 "구현"으로 세지 않았다.

> 아직 실제 Paper 서버에서 띄워 보지 못했다 (이 작업 환경은 Paper 를 받을 수 없어 Bukkit API 스텁으로 컴파일 · 단위 테스트만 한다).
> 출시 전에 실제 서버 스모크 테스트가 반드시 필요하다 — 맨 아래 체크리스트 참고.

## 3. NPC 생태계 (이번 단계)

| 사양 | 구현 내용 |
|---|---|
| 12-A 대규모 확장 | `npc_population.yml` 의 직업 틀 40종 × 지역 문화 → 결정적 생성기(지역 id 시드). 서버를 다시 켜도 같은 사람이 같은 자리에 있다 |
| 12-B NPC 데이터 | id · 이름 · 직업 · 지역 · 성격 · 레벨 · 일과 장소 · 대사 · 관계 · 상점 · 의뢰 · 기억 · 소문 · 숨은 의뢰 (`NpcProfile`) |
| 12-C 일과 AI | 일 · 집 · 시장 · 주점 · 광장 · 신전 · 성문 — 게임 시각에 따라 걷는다 |
| 12-D 지역 간 이동 | 떠돌이 19명: 가까운 도시를 차례로 돌고 도시마다 30분 머문다. 자리는 시각만으로 계산 (저장 없음, 서버가 꺼져 있던 동안에도 걸어간 셈) |
| 12-E 관계 단계 | 적대 · 냉담 · 처음 만남 · 인지 · 관심 · 우호 · 신뢰 · 친밀 · 동료 · 특별 관계. 단계마다 대사 · 할인 · 열리는 일 |
| 12-F 기억 | `npc_memory` (V6): 의뢰 · 선물(좋아함/싫어함) · 단골 · 지도 · 보스 토벌 · 가족에게 들은 이야기 → 대화 첫 줄 |
| 12-G NPC 끼리 관계 | 가족 · 사제 · 경쟁 · 주종 · 거래처. 호감이 크게 오르면 가족(30%) · 거래처/스승(20%) 에게 퍼지고 경쟁자는 반대로(-15%) |
| 12-H 가족 · 세대 | 한 집 1~3명, 부모 · 자식 · 형제 · 배우자 |
| 12-I 지역 문화 | 지역 태그별 직업 구성 (광산 마을 = 광부 · 대장장이, 항구 = 어부 · 상인 …) |
| 12-J NPC 경제 | 생산자는 가까운 시장 공급을 늘리고 소비자는 줄인다 (1시간마다, DB 스레드) |
| 12-K 동적 상점 | 관계 단계 할인 + 지역 번영 할인, 쇠퇴한 지역에선 귀한 물건 상인이 떠난다 |
| 12-L 떠돌이 | 행상 · 음유시인 · 용병 · 보물 사냥꾼 |
| 12-M 희귀 NPC | 6명 — 정해진 지역 · 날 · 시각에만 나타나고 높은 숙련을 가르친다 |
| 12-N 숨은 연쇄 | 신뢰에 이르면 그 NPC 의 숨은 의뢰가 열림, 소문이 아직 못 가 본 유적의 방향 · 거리를 알려 줌 |
| 12-O 의뢰 다양화 | 납품 · 처치 · 전달(관계 있는 NPC 에게) · 유적 찾기 · 제작 |
| 12-P NPC 의 일 | 소문 · 숙련 지도 · 숙소 · 치유 · 노래 · 수리 · 상점 · 선물 (모두 서버 서비스 + 창 버튼) |
| 12-R 세계 변화 연동 | 지역 번영(-1000~1000, 1주 반감기): 의뢰 · 거래 · 보스 토벌로 오르고, 단계(쇠퇴 · 평범 · 번성 · 융성)가 값 · 상인에 반영 |
| 12-U 성능 | 128 블록 칸 공간 색인 → 플레이어 주변 3×3 칸의 NPC 만 계산, 64 블록 밖은 엔티티 없음, 떠나 있는 상인은 5분마다 DB 스레드에서 캐시 |

관리자: `/va npc info <id>` (틀 · 관계 · 떠돌이 위치 · 희귀 시각 · 지역 번영), `/va perf` (NPC 수).
