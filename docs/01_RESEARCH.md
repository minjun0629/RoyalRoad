# 01. 원작 자료 조사 · 교차 검증

> 이 문서는 STEP 1(조사)과 STEP 2(교차 검증)의 결과입니다.
> **이 프로젝트는 원작의 공식 콘텐츠가 아닙니다.** 원작 자료는 철학과 구조를 참고하는 데만 씁니다.

## 0. 조사 방법과 한계

| 항목 | 내용 |
|---|---|
| 조사 도구 | 웹 검색 (나무위키 · 위키백과 · 팬 위키 문서의 검색 요약) |
| 접근 제한 | 개발 환경에서 나무위키 · 위키백과 · 팬 위키 **본문 직접 열람이 네트워크 정책으로 차단**됨. 검색 엔진이 보여 준 요약만 확인 가능 |
| 교차 검증 기준 | 서로 다른 두 검색 결과 이상에서 같은 내용이 확인되면 `CANON`. 한 곳뿐이거나 요약이 불분명하면 `RESEARCH_REQUIRED` |
| 다음 할 일 | 본문 열람이 가능한 환경에서 `RESEARCH_REQUIRED` 항목을 다시 확인하고, 이 문서를 고친다 |

분류:

- `CANON` — 원작 자료에서 확인된 사실 (이 게임에서는 **과거의 역사 · 전설**로만 쓴다)
- `SOURCE-BASED` — 원작 개념을 Minecraft 에 맞게 바꾼 시스템
- `ORIGINAL` — 후대 시대를 위해 새로 만든 것
- `RESEARCH_REQUIRED` — 자료가 부족해 확정할 수 없는 것

## 8. 이 게임이 가져가는 원작의 **철학** (구조만)

1. **행동이 곧 성장이다** — 사냥만이 아니라 생산 · 예술 · 탐험 · 대화도 캐릭터를 바꾼다.
2. **정해진 길이 없다** — 직업 제한이 약하고, 생활 직업도 전투 직업과 같은 무게를 가진다.
3. **물건에는 내력이 있다** — 내구도가 닳고, 고칠수록 최대 내구도가 줄어든다.
4. **발견하는 사람이 보상받는다** — 첫 발견 · 명성.
5. **죽음은 가볍지 않다** (단, 서버 게임에 맞게 완화 — 03_FEATURE_REGISTRY 참고).

## 9. 원작 히든 콘텐츠 처리 원칙

- 원작의 히든 직업 · 스킬 · 조건 · 획득 순서는 **하나도 그대로 쓰지 않는다.**
- 원작을 아는 사람이 원작 공략만으로 이 게임의 히든 콘텐츠를 열 수 없어야 한다.
- 히든 콘텐츠의 조건은 서버 데이터 폴더에 **봉인(암호화)** 해 두고, 플레이어의 실제 행동 기록으로 판정한다 (04_ARCHITECTURE §히든 엔진).
